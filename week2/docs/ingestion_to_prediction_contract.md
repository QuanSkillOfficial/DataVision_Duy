# Ingestion to Prediction Contract

Owner: Duy  
Consumer: Tuong - Prediction and ML Owner  
Purpose: Define the document metadata and text fields Duy's ingestion layer must provide to Tuong's document type classifier.

## Why This Contract Exists

Tuong's Week 3 prediction module needs a stable input payload for:

- document type classification
- prediction logging
- RAG metadata filtering
- Prediction page display in Phi/Hung's Streamlit demo

This contract defines the exact handoff from Duy's ingestion outputs to Tuong's `predict_document_type(input_payload)` function.

## Flow

```text
Uploaded document
  -> Duy PDF/file ingestion
  -> raw file storage
  -> extracted text and metadata
  -> prediction input payload
  -> Tuong document type classifier
```

## Required Prediction Input Fields

| Field | Type | Required | Produced by Duy | Description |
| --- | --- | --- | --- | --- |
| `document_id` | string | Yes | Yes | Stable ID for the document. Can be generated from source name and file name during prototype phase. |
| `source_id` | string | Yes | Yes | Stable ID for the source or ingestion run. Can use `run_id` from ingestion log. |
| `file_name` | string | Yes | Yes | Original file name, such as `policy_doc.pdf`. |
| `file_type` | string | Yes | Yes | File extension/type, such as `pdf`, `txt`, `csv`, `xlsx`. |
| `file_size` | integer | Yes | Yes | File size in bytes. |
| `text_length` | integer | Yes | Yes | Character length of extracted text. |
| `num_pages` | integer | Yes for documents | Yes for PDF | Number of PDF/document pages. Use `0` for non-document sources. |
| `source_system` | string | Yes | Yes | Origin of source, such as `manual_upload`, `api`, `batch_file`, or `streaming`. |
| `extracted_text` | string | Yes | Yes for PDF/text | Extracted text used by the classifier. Empty string is allowed but should lower confidence or trigger review. |

## Optional Fields

| Field | Type | Description |
| --- | --- | --- |
| `ingestion_run_id` | string | Ingestion log `run_id`. |
| `raw_output_path` | string/null | Project-relative raw output path. |
| `staging_output_path` | string/null | Project-relative extracted/staging output path. |
| `clean_output_path` | string/null | Project-relative clean output path if available. |
| `records_read` | integer | Rows/pages/records read during ingestion. |
| `records_valid` | integer | Valid rows/pages/records. |
| `records_invalid` | integer | Invalid rows/pages/records. |
| `empty_pages` | array | PDF pages with no extracted text. |
| `parsing_status` | string | `ready`, `partial_success`, `failed`, or `waiting`. |

```json
{

  "source_id": "c77b8cf3-d542-4242-af90-b5aa866715bf",
  "file_name": "DataFlow_Technical_Report.pdf",
  "file_type": "pdf",
  "file_size": 2857707,
  "text_length": 129028,
  "num_pages": 36,
  "source_system": "manual_upload",
  "extracted_text": "Extracted document text goes here...",
  "ingestion_run_id": "c77b8cf3-d542-4242-af90-b5aa866715bf",
  "raw_output_path": "data/raw/pdf/dataflow_technical_report_raw.pdf",
  "staging_output_path": "data/staging/pdf/dataflow_pdf_text.txt",
  "clean_output_path": "data/clean/pdf/dataflow_pdf_pages_clean.csv",
  "records_read": 36,
  "records_valid": 36,
  "records_invalid": 0,
  "empty_pages": [],
  "parsing_status": "ready"
}
```

## Empty Text Behavior

If `extracted_text` is empty:

- Duy should still send the payload.
- `text_length` should be `0`.
- `parsing_status` should be `partial_success` or `failed`, depending on the extraction result.
- Tuong should return `status = needs_review` or a low-confidence prediction.

## Field Mapping From Duy Outputs

| Tuong input field | Duy source |
| --- | --- |
| `document_id` | Generated by Duy from source/file metadata |
| `source_id` | `logs/*_ingestion_log.json.run_id` |
| `file_name` | Input path file name |
| `file_type` | Input file extension |
| `file_size` | Local source file size |
| `text_length` | `pdf_metadata.extracted_character_count` or length of extracted text |
| `num_pages` | `pdf_metadata.page_count` |
| `source_system` | `manual_upload` for current prototype |
| `extracted_text` | `data/staging/pdf/dataflow_pdf_text.txt` |
| `raw_output_path` | Ingestion log `raw_output_path` |
| `staging_output_path` | Ingestion log `staging_output_path` |
| `clean_output_path` | Ingestion log `clean_output_path` |

## Required From Tuong Back to Duy

Tuong should return:

```json
{
  "predicted_document_type": "policy_document",
  "confidence": 0.91,
  "model_version": "document_classifier_v1",
  "status": "accepted",
  "top_predictions": [
    {"label": "policy_document", "score": 0.91},
    {"label": "contract", "score": 0.06},
    {"label": "report", "score": 0.03}
  ]
}
```

This output can later be stored by Phat in `prediction_logs` and shown by Phi/Hung in the Prediction page.
