## Status Rules

| Condition | Status | Downstream Meaning |
| --- | --- | --- |
| `confidence >= 0.60` | `accepted` | Can be stored and displayed, but still review real-data correctness |
| `confidence < 0.60` | `needs_review` | Must go to manual review |
| `extracted_text` length < `50` | `waiting_for_source` | Ingestion text is not enough for reliable prediction |
| Validation error or exception | `failed` | Payload or service error |

## RAG Filtering Rule For Lap

Tuong's current real-data evaluation found overconfident mistakes. Therefore:

```text
Do not use low-confidence or unreviewed predictions as hard RAG filters.
```

Recommended rule:

| Status | Hard RAG Filter? | Reason |
| --- | --- | --- |
| `accepted` | Only after review or stricter confidence threshold | Current model can be overconfident on real data |
| `needs_review` | No | Low confidence |
| `waiting_for_source` | No | No reliable prediction |
| `failed` | No | Invalid prediction |

Recommended stronger Week 6 rule:

```text
Hard RAG filters should use only human-reviewed predictions or a stricter agreed confidence threshold.
For now, treat Tuong output as soft metadata unless Phi/Hung or a reviewer confirms it.
```
